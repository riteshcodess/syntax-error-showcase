# Syntax Error — Selected Work

A responsive portfolio and public-facing project catalogue for Syntax Error.

## Projects
- **Turfone** — multi-sided sports venue booking and operations platform (private source).
- **Turfo** — sports turf discovery and booking website (public source, intentionally public).
- **Syntax Error Toolbox** — browser-first developer, document, text and media utilities. Live: https://www.toolbox.run.place
- **Mr.X Wallpaper** — curated wallpaper marketplace concept (private source).
- **Future Fossil** — interactive public voice archive concept (public source).
- **Video Streaming Platform UI** — interface concept, not a production streaming service.

## Privacy
This repository contains project descriptions and portfolio presentation only. It does not contain source code copied from private repositories, credentials, environment files, customer data, or database exports.

## Run locally
Open `index.html` in a browser. This is a static site; no build step is required.
